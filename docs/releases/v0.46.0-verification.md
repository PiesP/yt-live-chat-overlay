## Verification coverage and known limits — 2026-11-03 addendum

The v0.46.0 source is `4f11a3931d1e1dfe935d46c7e6afb7a0c8347eda`
(core `b783358a3dd3bf167cf89a6df550166ded36dbd1`). The
[final admission](https://github.com/PiesP/yt-live-chat-overlay/issues/405#issuecomment-6600096713)
and [release closeout](https://github.com/PiesP/yt-live-chat-overlay/issues/405#issuecomment-6600336583)
identify the executed and reused checks for the published assets.

- **Public installed extensions:** Chrome 156 and Firefox 159 passed actual
  public live and replay pages, settings, pause/resume, content-associated
  seeking and cross-watch navigation. Rendering used Main after the observed
  host-policy Worker fallback. Separately reused controlled installed
  Worker/Main display checks and the Main Backlog fixture do not establish
  public Worker rendering.
- **Manual upgrades:** Tampermonkey userscript and unpacked Chrome extension
  upgrades from v0.45.9 to v0.46.0 passed with installation identity and
  settings checks. The post-publication Tampermonkey check used the public
  userscript. Automatic update discovery and store distribution were not
  verified.
- **Native and platform limits:** The separate advanced natural-Chrome path
  failed its guarded preconnect prerequisite. It supplies no current native
  tab-visibility, Picture-in-Picture or 20-minute duration acceptance;
  [#407](https://github.com/PiesP/yt-live-chat-overlay/issues/407) tracks that
  work. Historical [#268](https://github.com/PiesP/yt-live-chat-overlay/issues/268#issuecomment-6264646489)
  and [#276](https://github.com/PiesP/yt-live-chat-overlay/issues/276#issuecomment-6264138160)
  completed within their original Chrome 155, source
  `3411ee39b917f69549eeea1c154fc7470203051b`, core
  `77d30da018089be7e2a5e3b2197a200890547aee` and artifact scope. Public
  same-document SPA navigation, Android, Windows Firefox upgrades and store or
  automatic updates remain unverified. A later Firefox ad observation does not
  establish continuous ad-free operation.
