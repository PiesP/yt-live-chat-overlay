Design Audit: 5 Issues Found

  • Critical label.htmlFor syntax error — settings-ui-form.ts:646
    Code: label.htmlFor = `${colorId} ${checkboxId}`
    HTML htmlFor accepts a single ID. Two space-separated IDs are silently ignored → clicking label does nothing.
    Fix: label.htmlFor = colorId (or checkboxId)
  • High Section title rendered twice — settings-ui-form.ts:597-603
    domSection() creates a h3 title, then buildAuthorGrid() adds a <legend> with same text inside a <fieldset>.
    Result: "작성자 색상 � 표시" appears twice consecutively.
    Fix: Remove either domSection() call or <legend>
  • High Empty first header cell wastes space
    First header <span> occupies 1fr column. In narrow modals (320px), this squeezes label column and may clip text.
    Fix: Use only 2 grid columns (remove empty header cell column), or set first column to 0px when empty.
  • Medium SuperChat row alignment offset
    Other rows: [Label 1fr] [Color 44px] [Checkbox 18px]
    SuperChat: [Label 1fr] [Empty 0px] [Checkbox 18px]
    Checkbox is left-shifted compared to other rows.
    Fix: Add a placeholder color swatch for SuperChat (add to color settings) or insert empty styled span at same width.
  • Low Color input size is browser-dependent
    width: 44px; height: 26px on input[type="color"] may be overridden by UA styles in Firefox.
    Fix: Add appearance: none; border-radius: 4px; for cross-browser consistency.
