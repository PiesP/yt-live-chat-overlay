How to Preview Settings UI

  1. Build the project: cd yt-live-chat-overlay && pnpm build:dev
  2. Open the project in Chrome as unpacked extension, OR inject via Tampermonkey:
  • Chrome Extension: Copy manifest.json and built bundle to an extension folder, then load unpacked in Chrome.
  • Tampermonkey: From your browser where bundle is accessible, install a userscript that reads the dev bundle and injects it.

Note: Live preview on a real YouTube page is required because the bundle must detect the actual youtube.com hostname to initialize. This HTML page provides the DOM structure but cannot fully simulate YouTube's live chat data.

✨ Quick test with Playwright: Navigate to this page, addInitScript with the bundle and location override, then use an existing settings button selector to open the panel.

For visual regression tests, run the test file: test/e2e/specs/settings-visual.spec.ts (requires a real YouTube environment or mock).
